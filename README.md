# MantiA11y Academy - Learning Platform

Proyecto desarrollado por **Nira Mantilla Peña** como parte de la formación Full-Stack Web Development. Este proyecto es una plataforma de aprendizaje centrada en la accesibilidad web y la modularidad técnica.

##  Tecnologías y Metodologías
- **Estructura:** HTML5 Semántico.
- **Estilos:** SASS/SCSS utilizando la metodología **BEM** (Block Element Modifier) para escalabilidad.
- **Gestión:** Jira (Metodología Agile/Sprint).
- **Accesibilidad:** Cumplimiento con estándares **WCAG 2.2** (Contraste AA, tamaños de clic de 44x44px).
- **Diseño:** Figma (Prototipado de alta fidelidad).

## Estructura del Proyecto
El proyecto se organiza en componentes modulares siguiendo el diseño atómico:
- `hero.scss` / `features.scss`: Secciones principales de la Landing.
- `buttons.scss`: Sistema de botones interactivos con estados `:hover` y `:focus-visible`.
- `variables.scss`: Gestión de tokens de color "Inclusive Horizon".

##  Características Principales
1. **Landing Page:** Introducción a la metodología inclusiva.
2. **Página de Especificaciones:** Panel Sensorial para ajustes de interfaz y bloques de código técnico.
3. **Formulario de Contacto:** Proceso de solicitud accesible y validado.
